# Portfolio Assets Directory

Place your high-resolution portfolio images, custom fonts, and brand logos here.

## Directory Structure:
- `/public/projects/` — Place case study covers and gallery images.
- `/public/tools/` — Custom SVG software icons if replacing inline defaults.
- `/public/fonts/` — Custom web fonts (e.g. Neue Haas Grotesk, Rezan, etc.).

## Recommended Image Dimensions:
- Hero / Case Study Covers: 1600 × 1000 px (JPEG or WebP, optimized under 300KB)
- Project Card Thumbnails: 1200 × 800 px
- Software Icons: Vector SVG or transparent PNG (128 × 128 px)
